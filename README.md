# Hussain Khan — Official Website

Static bilingual portfolio/product website designed for deployment on 4EVERLAND, Cloudflare Pages, Kinsta Static or any static host.

## Fonts
The CSS is already configured for the user's PNU font files. For licensing/safety the font binaries are not included in this package. Place your original files here after extracting:
- assets/fonts/PNU-Regular.ttf
- assets/fonts/PNU-Bold.ttf

## Deploy
Upload the folder to GitHub and connect the repository to 4EVERLAND. Build command: none. Output directory: root (`.`).
