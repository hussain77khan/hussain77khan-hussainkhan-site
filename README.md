# Hussain Khan Website v0.2.0

Static bilingual portfolio website prepared for GitHub + 4EVERLAND.

## Included
- Responsive cinematic dark/gold UI
- Arabic / English switcher
- Home, Portfolio, Films, Plugins, HK Cinematic Suite, DCTL, Downloads, About, Contact
- Privacy, Terms, 404
- SEO metadata, robots.txt and sitemap.xml
- Web3Forms-ready contact form

## Fonts
The CSS is prepared for:
- assets/fonts/PNU-Regular.ttf
- assets/fonts/PNU-Bold.ttf

Add your licensed local copies to that folder after upload if desired.

## Contact form
Replace `YOUR_ACCESS_KEY` in `contact/index.html` with a Web3Forms access key.

## Downloads
Replace the placeholder download items with final 4EVERLAND Storage/CDN URLs when ready.
